## 🧩 About

**Assassins Creed Shadows Companion** is a curated list of Assassins Creed Shadows open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD viewer, waypoint markers
- **Quality-of-Life Helpers** — gear catalog, loadout manager, overlay notes
- **Research Notes** — stealth route layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Playthrough Helpers
- Waypoint Notes — practice routes from any vantage point
- Show Markers — visualize points of interest in the world
- Replay Notes — record and review stealth runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Gear Catalog — browse outfits, colors, weapons, trinkets
- Custom Loadout Notes — organize player gear
- Clear Marker Trail — improved route visibility

### 🏋️ Stealth Layout
- Stealth Mode Notes — segment study on any compound layout
- Vantage Toggle — manually switch study viewpoints mid-route
- Grapple Notes — chain complex traversal in the editor
